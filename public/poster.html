The problem

12 FIRs. 34 entities. One investigation — scattered across phone numbers, bank accounts, UPI handles, aliases, people and places. The links that matter are the ones nobody wrote down.

Conventional tooling ranks these with hand-written heuristics. Those are defensible, but blind to structure a model can learn: the neighbourhood an entity sits inside, not just the row describing it.

The model is a real GCN

A Kipf & Welling graph convolutional network — not a metaphor for one. Two convolutions aggregate each entity's neighbourhood before anything is predicted.

Inputs are 16 structural features per entity: type, declared network, degree, case count, instrument flag, recency, mean evidence confidence and source spread. Glorot initialisation from a seeded mulberry32 PRNG, so the same corpus always produces the same weights.

Both labels are derived from facts already in the corpus, so the neighbourhood term is what generalises them — not a memorised lookup.

In-sample AUC is reported so it can be dismissed. A model always scores well on its own training data — the held-out column is the finding.

The link head reconstructs co-occurrence edges it never saw, then proposes pairs that appear in no record at all. Its negatives are drawn from the same instrument-to-instrument population it is later asked to rank, so its AUC describes the predictions actually shown — not an easier proxy task.

Weights come from the best-validation epoch, not the last one. The validation slice is withheld from the gradient entirely and used only to choose when to stop — because at ten labels it selects an epoch, it cannot support an AUC.

Structure recovered without being told

Clustering the learned vectors — with the declared network label never used as an input — recovers 4 communities at 1.00 purity. Independent evidence that the features carry real structural signal.

The report drafter assembles six sections from live computed values — so a wrong number is visible in the row beside it. 14 of 66 instrument pairs are recorded; the remainder are where the model looks for gaps.

What this does not claim. The reuse head rests on 8 positives and the link head on 14 — both are shortlists, not findings. The system ranks leads for human review; it does not determine guilt, does not establish criminal liability, and is not a charge sheet. All entities and FIRs are synthetic.
